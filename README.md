# Aerial Hunter — website

Static site for **Aerial Hunter**, a thermal drone search and recovery service based in Rockville, Indiana, serving the whole state
(deer recovery, lost pet recovery, herd counts and land surveying). Phone: 765-592-5970.
Facebook: https://www.facebook.com/people/Aerial-Hunter/61583336984487/

Live: https://justuseflint.github.io/aerial-hunter/

## Stack
Plain HTML, CSS and JavaScript. No framework, no build step needed to serve.
Motion uses GSAP + ScrollTrigger and Lenis (vendored in `assets/vendor/`). Fonts: Archivo and JetBrains Mono (Google Fonts).
Pages are generated by `node _build/build.mjs` from `_build/data.mjs` (copy) and `_build/pages.mjs` (templates).
Respects `prefers-reduced-motion`.
